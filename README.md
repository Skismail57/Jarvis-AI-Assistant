## 🚀 Quick Start

### Prerequisites
- Python 3.8+
- pip (Python package manager)
- Node.js 16+ (for frontend development)
- Git
- Tesseract OCR (for screen text extraction)

### Installation

1. **Clone the repository**
```bash
git clone <repository-url>
cd "Ai Voice Assstant"
```

2. **Install Python dependencies**
```bash
pip install -r requirements.txt
```

3. **Install Tesseract OCR** (for screen text extraction)
- **Windows**: Download from [UB Mannheim](https://github.com/UB-Mannheim/tesseract/wiki)
- **macOS**: `brew install tesseract`
- **Linux**: `sudo apt install tesseract-ocr`

4. **Install Face Recognition dependencies** (for biometric authentication)
```bash
pip install face-recognition dlib
```

5. **Set up environment variables**
Create a `.env` file in the root directory:
```env
# LLM API Keys (optional but recommended for full functionality)
OPENAI_API_KEY=your_openai_key_here
GEMINI_API_KEY=your_gemini_key_here
ANTHROPIC_API_KEY=your_anthropic_key_here
OPENROUTER_API_KEY=your_openrouter_key_here

# Wake Word (optional - for Porcupine)
PORCUPINE_ACCESS_KEY=your_porcupine_key_here

# Productivity Integrations (optional)
SLACK_BOT_TOKEN=your_slack_bot_token
SLACK_WEBHOOK_URL=your_slack_webhook_url
DISCORD_BOT_TOKEN=your_discord_bot_token
DISCORD_WEBHOOK_URL=your_discord_webhook_url
TODOIST_API_TOKEN=your_todoist_token
NOTION_TOKEN=your_notion_token
NOTION_DATABASE_ID=your_notion_database_id

# Smart Home (optional)
HOME_ASSISTANT_URL=http://home-assistant.local:8123
HOME_ASSISTANT_TOKEN=your_ha_token
IFTTT_WEBHOOK_KEY=your_ifttt_key
```

6. **Run diagnostic tests**
```bash
python main.py --test
```

### Basic Usage

**Text Mode** (no microphone required):
```bash
python main.py --text
```

**Voice Mode** (with microphone):
```bash
python main.py --voice
```

**Wake Word Mode** (continuous listening):
```bash
python main.py --wake
```

## 🔐 Authentication System

### Web Interface with Authentication

**Start the Backend Server:**
```bash
python -m uvicorn assistant.server.app:get_app --host 0.0.0.0 --port 8000
```

**Start the Frontend:**
```bash
cd frontend
npm install
npm run dev
```

**Access the Interface:**
- Visit `http://localhost:3000` (or the port shown in terminal)
- You'll be redirected to the login page

### Authentication Methods

#### 1. **Regular Login (Username/Password)**
1. Pull the lamp cord to activate the login form
2. Enter your username and password
3. Click "Login"

#### 2. **Create Account (Sign Up)**
1. Click "Create Account" link on login page
2. Fill in username, password, and optional email
3. Click "Sign Up"
4. You'll be automatically logged in

#### 3. **Biometric Authentication**
**Setup (One-time enrollment):**
1. Go to `/enroll` after creating an account
2. Enter your username
3. Choose "Face Recognition" or "Voice Recognition"
4. For Face: Allow camera access and capture your face
5. For Voice: Allow microphone access and record your voice
6. Click "Complete Enrollment"

**Login with Biometrics:**
1. Go to login page
2. Enter your username
3. Click "🔐 Face/Fingerprint Login"
4. System will authenticate using enrolled biometrics

### Authentication Features
- **Secure Token Storage**: JWT tokens with 7-day expiration
- **Session Management**: Active session tracking
- **Account Lockout**: Protection against brute force attacks
- **Biometric Enrollment**: Face and voice template storage
- **Multi-Factor Authentication**: Combine multiple biometric methods
- **Audit Logging**: Track all authentication attempts

### API Authentication Endpoints
- `POST /api/auth/login` - Login with username/password
- `POST /api/auth/signup` - Create new account
- `POST /api/auth/logout` - Logout user
- `GET /api/auth/verify` - Verify authentication token

## 🔧 Configuration

### Voice Settings
- **STT Engine**: `--stt-engine sr` (default) or `whisper`
- **TTS Engine**: `--tts-engine pyttsx3` (default) or `gtts`
- **Language**: Set `JARVIS_LANGUAGE` in `.env` (default: `en-US`)
- **Wake Word**: Set `WAKE_WORD` in `.env` (default: `jarvis`)
- **Wake Sensitivity**: Set `JARVIS_WAKE_SENSITIVITY` (0.0-1.0, default: 0.65)

### LLM Settings
- **Model**: `--llm auto` (default) or specify `gpt-4o`, `gemini-1.5-flash`, `claude-3-haiku`
- **Agent**: Disable with `--no-agent` for faster but simpler responses
- **Temperature**: Set `LLM_TEMPERATURE` in `.env` (0.0-1.0, default: 0.7)

### Memory Settings
- **Conversation History**: `MAX_CONVERSATION_HISTORY=200` in `.env`
- **Vector Memory**: Toggle with `ENABLE_VECTOR_MEMORY=true`
- **Top-K Results**: `VECTOR_MEMORY_TOP_K=5`
- **Min Score**: `VECTOR_MEMORY_MIN_SCORE=0.35`

### Authentication Settings
- **Token Expiration**: Set `TOKEN_EXPIRATION_DAYS` (default: 7)
- **Max Failed Attempts**: Set `MAX_FAILED_ATTEMPTS` (default: 5)
- **Account Lockout Duration**: Set `ACCOUNT_LOCKOUT_MINUTES` (default: 30)

### Security Settings
- **Enable Biometric**: Set `ENABLE_BIOMETRIC_AUTH=true`
- **Face Recognition Threshold**: Set `FACE_RECOGNITION_THRESHOLD` (0.0-1.0, default: 0.7)
- **Voice Recognition Threshold**: Set `VOICE_RECOGNITION_THRESHOLD` (0.0-1.0, default: 0.7)

## 🎨 Customization

### Creating Custom Plugins

Create a new file in `plugins/` folder:

```python
# plugins/my_skill.py
PLUGIN_NAME = "My Custom Skill"
ICON = "🎯"
INTENT_PATTERNS = [
    r"do something cool",
    r"perform action",
]
EXAMPLES = [
    "do something cool",
    "perform action",
]

def handle(text, match=None, assistant=None):
    # Your skill logic here
    return {
        "text": "I performed the action!",
        "intent": "my_skill",
        "data": {"result": "success"}
    }
```

### Adding Custom Voices

Edit `assistant/voice/multilingual.py` to add more edge-tts voices:

```python
_EDGE_VOICES = {
    "your-locale": {
        "male": "voice-id",
        "female": "voice-id",
    },
}
```

## 🐛 Troubleshooting

### Voice Not Working
- Check microphone permissions
- Verify `pyaudio` installation: `pip install pyaudio`
- Try different STT engine: `--stt-engine whisper`

### LLM Not Responding
- Verify API keys in `.env`
- Check internet connection
- Try different LLM provider

### Vector Memory Issues
- Install sentence-transformers: `pip install sentence-transformers`
- Check ChromaDB installation: `pip install chromadb`
- Clear memory: `DELETE /api/memory?kind=all`

### Frontend Not Connecting
- Ensure FastAPI server is running on port 8000
- Check proxy settings in `vite.config.js`
- Verify WebSocket connection in browser console
- Check if ports are in use: `netstat -ano | findstr :8000`

### Authentication Issues
- Clear browser cookies and localStorage
- Verify backend is running: `curl http://localhost:8000/api/health`
- Check user data in `data/users.json`
- Reset authentication: Delete `data/tokens.json`

### Biometric Authentication Not Working
- Install face recognition: `pip install face-recognition dlib`
- Check camera/microphone permissions
- Verify enrollment status: `POST /api/auth/check-biometric`
- Check biometric data in `data/biometric_auth/`

### Face Recognition Installation Issues
- **Windows**: Install CMake and Visual Studio Build Tools
- **macOS**: `brew install cmake dlib`
- **Linux**: `sudo apt install cmake libdlib-dev`
- Alternative: Use virtual environment with pre-built wheels
